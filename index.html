Velkommen til
Det er enkelt å invitere venner til spillet:
- Trykk på «Del invitasjon», og del invitasjonen eller kopier lenken.
- Du kan også sende spillnummeret som står øverst på skjermen.
Når vennene dine er inne, vil alle se det samme og dere kan spille sammen.
Vil du spille på denne enheten, trykk på «Bli med som spiller» og velg spillernavn.
Hvis du ikke spiller på denne enheten, kan den ligge på bordet og vise kortene dere legger ut.
Du kan legge til én eller flere boter med «Legg til bot».
Når det er to eller flere spillere, kan dere starte med «Start spill».
Trykk på et kort for å velge det; like kort velges sammen. Sveip sidelengs for å bla i hånden. Dra eller flick utvalget opp for å legge det ut, eller trykk Enter.

Legg på kort
Du kan ikke legge på det kortet nå.
Legg på like mange kort med samme eller høyere verdi: singel på singel, par på par, tress på tress og fire like på fire like. Kløver 3 er jokeren og kan legges på alt. Fire like rydder bunken straks.
Regler
Mål
Bli kvitt kortene først: første blir President, siste Boms.
Legg ut
Legg samme antall som øverst, med lik eller høyere verdi. Singel, par, tress og fire like må matche.
Start
Første runde starter spilleren med Hjerter 3. Etter bytte starter Boms.
Tre spillere
Ruter 3 tas ut. Hjerter 3 og Spar 3 sammen øverst rydder bunken.
Spesialkort
Kløver 3 kan legges på alt og rydder bunken, men taper hvis det er siste kort. Fire like rydder også; spilleren starter igjen.
Pass
Pass er bare mulig når bunken ikke er tom. Når alle andre passer, ryddes bunken; siste spiller starter igjen, eller neste aktive hvis hen er ferdig.
