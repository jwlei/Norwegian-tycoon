Velkommen til
Det er enkelt å invitere venner til spillet:
- Trykk på «Del invitasjon», og del invitasjonen eller kopier lenken.
- Du kan også sende spillnummeret som står øverst på skjermen.
Når vennene dine er inne, vil alle se det samme og dere kan spille sammen.
Vil du spille på denne enheten, trykk på «Bli med som spiller» og velg spillernavn.
Hvis du ikke spiller på denne enheten, kan den ligge på bordet og vise kortene dere legger ut.
Du kan legge til én eller flere boter med «Legg til bot».
Når det er to eller flere spillere, kan dere starte med «Start spill».
Trykk på et kort for å velge det; like kort velges sammen. Sveip sidelengs for å bla i hånden. Dra eller flick utvalget opp for å legge det ut, eller trykk Enter.

Inviter andre spillere
Del invitasjonslenken, så åpnes dette rommet direkte. Spillnummer:
Legg på kort
Du kan ikke legge på det kortet nå.
Legg på like mange kort med samme eller høyere verdi: singel på singel, par på par, tress på tress og fire like på fire like. Kløver 3 er jokeren og kan legges på alt. Fire like rydder bunken straks.
Regler
Målet
Bli kvitt alle kortene først. Første spiller blir President, og siste blir Boms.
Legg på kort
Legg på like mange kort som ligger øverst, med samme eller høyere verdi: singel på singel, par på par, tress på tress og fire like på fire like. En vanlig singel kan ikke legges på et par eller tress.
Tre spillere
Ruter 3 tas ut av kortstokken. Kløver 3 er joker, så det er bare to vanlige treere. Når Hjerter 3 og Spar 3 ligger sammen øverst, ryddes bunken som ved fire like.
Første runde
Når alle er nøytrale, begynner spilleren med Hjerter 3.
Kløver 3
Kan legges på hvilken som helst bunke eller på tomt bord og rydder bordet. Kløver 3 kan ikke være siste kort; da taper spilleren.
Fire like
Når fire like ligger øverst, ryddes bunken straks. Spilleren som la dem får starte på nytt.
Pass
Når alle andre passer, ryddes bunken og siste spiller som la kort starter igjen. Hvis spilleren som la sist har gått ut, og de to gjenværende passer, får neste aktive spiller etter spilleren som gikk ut legge ut.
